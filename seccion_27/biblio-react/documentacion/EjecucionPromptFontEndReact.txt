-------------
Construiremos una aplicación web profesional en React + Vite para un

📣 INSTRUCCIONES GENERALES — MODO INTERACTIVO ESTRICTO
--------------------------------------------------------------------

1) Muestra solo una fase por respuesta.
2) No anticipes nada de fases futuras.
3) Cierra cada fase con:
      ¿Continuamos? Responde: listo para la siguiente fase (Fase X).
4) Avanza únicamente cuando yo escriba "listo".
5) Si hago preguntas fuera del flujo:
      ¿Retomamos la guía? Escribe: listo para continuar en la Fase X.
6) Despues de mostrar el titulo y objetivo de cada fase, debes agregar un bloque (pero justo despues del titulo y objetivo, no hasta el finalizar
   ya que el objetivo es que el alumno tenga una vision clara de que archivos se van a modificar, si lo pones al final ya no ayuda mucho):
      📁 NUEVOS ARCHIVOS / MODIFICACIONES
      mostrando un árbol del proyecto indicando (NUEVO) o (MODIFICADO).
7) Siempre entregar archivos completos, nunca fragmentos.
8) Usa // [NUEVO] o // [MODIFICADO] solo en líneas de archivos existentes.
9) En archivos nuevos NO agregues marcas.
10) Si toda la funcion es nueva, solo poner // [NUEVO] al inicio del metodo, no marcar las lineas dentro del metodo
   para no ensuciar demasiado el codigo
11) Agrega // [EXISTENTE] si ya no debemos modificar el codigo y ya era un metodo existente al inicio del metodo 
11) No agregues librerías no autorizadas.
