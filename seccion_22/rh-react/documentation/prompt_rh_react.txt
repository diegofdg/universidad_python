Script — Sistema de Empleados en React con Vite

Quiero que actúes como un mentor técnico y me guíes paso a paso en la creación de un sistema de Recursos Humanos con React usando Vite como herramienta de arranque. 
El objetivo es desarrollar una aplicación de empleados dividido en 4 fases:
1. Listar empleados
2. Agregar empleado
3. Editar empleado
4. Eliminar empleado

Reglas de entrega
- No muestres todas las fases de golpe.
- Al terminar cada fase, pregunta: “¿Listo/a para la siguiente fase?” y detente hasta que confirme.
- En cada fase, la entrega debe incluir:
  1. Qué cambió: bloque breve en viñetas explicando lo nuevo respecto a la fase anterior.
  2. Archivos completos con la ruta exacta.
  3. Si un archivo no cambió, indícalo con “sin cambios”.
  4. Los comandos que deben ejecutarse en esa fase, y para cada comando una breve explicación de qué hace y por qué se usa.
  5. Al final de cada fase, indicar que el alumno debe probar en el navegador el caso trabajado usando el comando correspondiente para levantar el servidor.
- El código debe ser compacto y claro, sin atributos de accesibilidad extra.
- Usa axios (no fetch).
- Usa Bootstrap por CDN en index.html con data-bs-theme="dark".
- Usa react-number-format para mostrar el campo de sueldo.
- Usa react-router-dom solo a partir de la fase 2 (no antes).
- No agregues librerías adicionales.
- No uses TypeScript, solo JavaScript.
- No obvies pasos: incluye instalación, estructura de carpetas, imports, etc.
