### 🎯 FASE 1: CREACIÓN DEL PROYECTO Y MODO OSCURO (QDarkStyle)
**Por qué:** Validar entorno, dependencias y una ventana base **con dark theme** desde el inicio.

**Qué hacer:**

   - Ruta final: `C:\Cursos\PySide\pyside_mascotas`  
   - Activa **entorno virtual (venv)**.

2) Usar el intérprete 3.13 para este proyecto (recomendado) con PySide.
- En PyCharm:  
  Settings → Python → Interpreter → Add Interpreter → Base Python: 3.13.x → seleccionar .venv1 (No el existente)  
  Opcionalmente puedes eliminar el .venv anterior, ya no se necesita, solo dejar el nuevo .venv1 que apunta a la version 3.13
  Confirmar que el proyecto usa el nuevo .venv1 para que detecte la nueva version 3.13
**Por qué:** PySide6 aún no publica ruedas para 3.14+; 3.13 es estable y compatible.

3) **Actualizar e instalar dependencias**  
   - Actualiza `pip`.  
     ```
     python.exe -m pip install --upgrade pip
     ```
   - Instala:
     ```
     pip install PySide6 qdarkstyle SQLAlchemy Alembic python-dotenv PyMySQL cryptography
     ```
     > `qdarkstyle` provee el tema; `cryptography` es necesaria para autenticación de MySQL 8+ (caching_sha2_password).

### 📋 FASE 6: LISTAR MASCOTAS (READ) – PRIMERA VERSIÓN EN UNA SOLA VENTANA
**Por qué:** Validar fin a fin la integración entre BD → modelo → servicio → UI, mostrando los datos reales en pantalla.

**Qué hacer:**

- Generar un SQL para Insertar **3 mascotas** de ejemplo en MySQL Workbench (SQL directo).

- **Archivo (MODIFICADO): `app.py`**  
  Genera el código completo para que el archivo `app.py` incluya lo siguiente:

  #### ✔ Diseño visual y distribución
  - Mantener el **título principal** y el **subtítulo** centrados.
  - La tabla debe aparecer **debajo del subtítulo**, no hasta abajo.
  - NO debe existir separación vertical exagerada entre encabezados y tabla.
  - Evitar que el layout “empuje” la tabla al fondo:  
    - Usar `layout.setAlignment(Qt.AlignTop)`  
    - Usar márgenes superiores e inferiores moderados.
    - No usar `layout.addStretch()`.

  #### ✔ Contenedor central profesional
  - La UI debe comportarse como un dashboard:
    - Encabezado arriba.
    - Subtítulo debajo.
    - Tabla inmediatamente después del subtítulo.
  - **No centrar verticalmente.**
  - **No permitir que la tabla se desplace hacia el fondo cuando la ventana es grande.**

  #### ✔ Configuración profesional de la tabla (`QTableView`)
  La tabla debe:
  - Ajustar automáticamente el ancho de **todas las columnas** para rellenar el espacio.
  - No mostrar scroll horizontal.
  - Mostrar scroll vertical solo si es necesario.
  - Ocultar la **cabecera vertical**.
  - Eliminar bordes azules o frames con una hoja de estilo.
  - Conservar filas con altura consistente.
  - Recordatorio importante:  
    Si usas la constante antigua:
    ```
    header.setSectionResizeMode(i, header.Stretch)
    ```
    debe reemplazarse por:
    ```
    header.setSectionResizeMode(i, QHeaderView.Stretch)
    ```

  #### ✔ Adaptabilidad (responsive)
  - La tabla debe adaptarse correctamente al crecimiento o reducción de la ventana.
  - La tabla debe mantener su estética:
    - centrada
    - con ancho máximo agradable
    - sin ocupar todo el espacio sobrante
  - Evitar que se despegue demasiado del encabezado.
  - Mantener un estilo tipo dashboard moderno en modo oscuro.

  #### ✔ Lógica
  - Implementar una función temporal `obtener_todos()` para cargar los registros y llenar el modelo del `QTableView`.
